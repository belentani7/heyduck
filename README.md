# HEYDUCK

Portafolio web estático e interactivo de producción musical. `index.html` es la entrada canónica; `02-DUCK-FUSIONADO-COMPLETO.html` y `DUCK-MEGA-UNIFICADO.html` se conservan como variantes para revisión editorial, sin consolidación destructiva.

## Uso local

```bash
npx serve .
npm test
```

El asistente de estudio funciona localmente con respuestas predefinidas. Las preguntas del visitante se insertan como texto y la respuesta admite únicamente `<strong>` y `<br>` mediante una lista segura.

Antes de publicar, validar con el artista las cifras, créditos, derechos de imágenes y datos de contacto mostrados en la web.
