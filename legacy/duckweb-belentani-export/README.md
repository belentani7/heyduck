# Exportación Duckweb / Belentani

Paquete de respaldo del contenido producido en la tarea: proyecto web Duckweb, manuscritos, PDFs, fuentes DOCX/TXT, archivo comprimido original, copia del chat, activos visuales y referencias de checkpoints.

## Estructura

| Carpeta | Contenido |
|---|---|
| `website/` | Código fuente del proyecto Duckweb, sin dependencias instaladas, build ni logs temporales. |
| `documentos/` | Manuscritos Markdown y versiones PDF generadas durante la tarea. |
| `fuentes/` | Documentos fuente proporcionados en la carpeta comprimida. |
| `adjuntos/` | Chat original y archivo ZIP original aportado por el usuario. |
| `activos/` | Activos visuales persistentes usados por la web. |
| `metadatos/` | Registro de versiones y alcance de la exportación. |

## Nota de seguridad

Se excluyeron secretos, tokens, credenciales, dependencias instaladas, builds y logs operativos. El archivo de chat y los documentos personales se incluyen porque forman parte explícita de la solicitud de exportación.
