## Decisión de dirección

`duck-ink-playground.html` es la candidata principal. Debe unificar la información fiable del portfolio original con una experiencia visual propia. El hero comunica en cinco segundos: **DUCK**, productor musical, rostro real, subfrase corta y una acción clara. La experiencia no se presenta como artículo editorial.
